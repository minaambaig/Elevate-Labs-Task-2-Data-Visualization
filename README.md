# Power BI Sales Dashboard

## Project Overview

This project was completed as part of the Data Analyst Internship Task 2:
Data Visualization and Storytelling.

The objective was to create an interactive Power BI dashboard that converts
sales data into meaningful business insights.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- GitHub

## Project Files

- `Superstore_Sales_Dashboard.pbix` – Power BI dashboard
- `Superstore.csv` – Dataset used for the project
- `Dashboard_Screenshot.png` – Dashboard preview
- `Dashboard_Report.pdf` – Exported dashboard report

## Dashboard Features

- Key performance indicator cards
- Sales and profit analysis
- Category and product analysis
- Regional performance analysis
- Time-based sales trends
- Interactive slicers and filters

## Key Insights

- The dashboard identifies the categories generating the highest sales.
- It compares sales and profitability across different regions.
- It highlights changes in sales performance over time.
- It helps identify strong and underperforming products or categories.
